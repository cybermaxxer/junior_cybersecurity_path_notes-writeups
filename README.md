	 htb junior cybersecurity path notes

personal study notes for hack the box's **junior cybersecurity analyst** path, one markdown file per section/module. built for fast review, not for reading front to back.

> ⚠️ covers retired and free/tier 0 htb academy content only, per htb's terms of service. no active machine, challenge, or sherlock content lives here.

## why this exists

academy modules are long. these notes strip each one down to the 20% that actually builds understanding, so review takes minutes, not hours. every file follows the same shape:

- **the 80/20 digest** — the actual theory, broken into small chunks with a quick cause/effect check after each one
- **cheat sheet table** — concept, explanation, and where it's used in practice, all scannable at a glance
- **feynman checks** — a few open questions that test real understanding, not just definitions
- **omitted chuff** — a short list of what got cut and why, so nothing important slips through unnoticed
